# Examples

This directory contains example scripts demonstrating how to use AI Creator.

## Basic Usage

Run the basic usage example:

```bash
python examples/basic_usage.py
```

## Examples Included

- `basic_usage.py`: Demonstrates core functionality including text generation, image creation, and content analysis

## Creating Your Own Examples

Feel free to create your own examples based on these templates. Make sure to:

1. Import the necessary modules from `ai_creator`
2. Initialize the `Creator` class
3. Use the available methods for your AI tasks
4. Handle any errors appropriately
